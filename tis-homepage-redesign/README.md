# Tulas International School - Homepage Redesign

A modern and responsive redesign of the Tulas International School homepage, built with React.js.

## Overview

This project redesigns the Tulas International School website with a modern visual style while retaining the school's original branding, content, images, and key information.

The homepage is designed to provide a smooth and engaging experience across desktop, tablet, and mobile devices.

## Features

- Responsive design for desktop, tablet, and mobile
- Modern Tulas International School themed UI
- Animated hero section
- Scroll-based section reveal
- Interactive sports section
- Rankings and statistics section
- Influential personalities section
- Awards showcase
- Parent testimonials and Google Reviews
- Horizontal review cards
- Collaborations showcase
- Google Maps integration
- Responsive footer
- Smooth hover interactions
- Mobile-friendly horizontal card scrolling

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Lucide React
- Google Maps Embed

Installation
Clone the repository:
git clone <your-github-repository-url>

Navigate into the project:
cd <project-folder>

Install dependencies:
npm install

Start the development server:
npm start

The application will run locally at:
http://localhost:3000

Production Build
To create a production build:
npm run build

Responsive Design
The website has been tested for:
- 375px mobile screens
- 768px tablet screens
- 1280px desktop screens
The layout adapts automatically across different screen sizes.
Key Design Features
Interactive Hero
The hero section combines Tulas activity imagery with the school's visual identity to create an engaging first impression.
Sports Showcase
The sports section displays 16 sports using interactive cards and responsive navigation.
Parent Reviews
Parent reviews are displayed as horizontally scrollable white cards with parent images, names, relationships, and review content.
Collaborations
The collaborations section showcases Tulas International School's global academic and institutional collaborations.
Responsive Footer
The footer includes the school location through Google Maps, contact information, and useful navigation links.
